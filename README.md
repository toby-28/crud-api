# 🧩 CRUD API

A simple RESTful API for managing users, built with Node.js and TypeScript. This project uses an in-memory database and is designed to meet the RS School CRUD API assignment requirements.

## 🚀 Features

- Full CRUD operations on `/api/users`
- In-memory data storage
- UUID-based user identification
- Robust error handling
- Environment-based port configuration
- Horizontal scaling with Cluster API

## 📦 Tech Stack

- Node.js v24.x.x
- TypeScript
- UUID
- dotenv
- ts-node-dev / nodemon
- Cluster API (for multi-process support)

## 📚 API Endpoints

| Method | Endpoint              | Description                  | Status Codes |
|--------|-----------------------|------------------------------|--------------|
| GET    | `/api/users`          | Get all users                | 200          |
| GET    | `/api/users/{id}`     | Get user by ID               | 200, 400, 404|
| POST   | `/api/users`          | Create new user              | 201, 400     |
| PUT    | `/api/users/{id}`     | Update user by ID            | 200, 400, 404|
| DELETE | `/api/users/{id}`     | Delete user by ID            | 204, 400, 404|

### 🧑 User Object Format

```ts
{
  id: string;        // UUID, generated by server
